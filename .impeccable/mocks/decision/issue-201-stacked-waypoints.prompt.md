## Prompt

Create one polished, realistic first-viewport product UI comp for Nova's authenticated Club Overview, direction **Stacked Waypoints**. This is a full-fidelity decision comp, not a wireframe, browser frame, or device mockup.

Use a landscape 1440×900 edge-to-edge web viewport. Structure the interface from left to right as: a visible but secondary authenticated Nova global rail; a stable local Club directory about 15rem wide; and one broad, dominant working hall.

The global rail uses a simple Nova diamond mark and restrained destinations Home, Club, Players, and Campaigns, with Club current. The local directory is headed Club and shows all administrator routes in this exact order: Overview, Seasons, Teams, Members, Requests, Tags, Crest. Overview is active with a Sea Glass field and Wayfinding Teal left edge marker. Labels are fully written, aligned, and wrap-safe—never abbreviated or truncated.

The working hall is headed Club overview. Show a believable, simple, flat geometric crest beside Northstar United and Madison, Wisconsin. Below identity, create a connected vertical orientation route with circular semantic stops and a thin rule. The first stop reads Current season, 2026–27, August 2026–June 2027. The second reads Active work, Fall Supplemental Tryouts, Active, with exactly one primary action labeled Open campaign. Markers express orientation, not wizard completion: no checkmarks, step numbers, percentages, or completion language.

Use Fieldhouse Wayfinding only: Foam Mist ground, Paper White flat boards, Sea Glass active fields, Wayfinding Teal only for active navigation/route/action, ink-dark system sans typography, precise one-pixel roster hairlines, compact square radii, and operational spacing. Preserve a page-title scale near 2rem, section-title scale near 1.25rem, labels at least 0.875rem, keyboard-focus-ready space, and 2.75rem target scale. Every status is written.

Avoid shadows, gradients, glass effects, generic SaaS card mosaics, decorative pills, charts, counts, metrics, soccer balls, stadiums, field diagrams, athlete photography, ornamental sports motifs, invented claims/data, watermarks, browser chrome, and perspective.
